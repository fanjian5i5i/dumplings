# Mystery Dumpling Boxes

A browser-based mystery box game where the player opens 1 box out of 3 and gets a dumpling.

## Dumplings

- Ozy (blue)
- Golden (golden)
- Glow (glow in the dark)
- mimi (purple)

## How to run

Open `index.html` in your browser.

## Gameplay

- Each round presents 3 mystery boxes.
- You can open exactly one box.
- The revealed dumpling is added to your collection.
- Click "Play Next Round" to continue.
